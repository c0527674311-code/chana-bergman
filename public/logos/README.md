# לוגואים של חברות

הלוגואים בקיר הלוגואים מוגדרים ב-`src/components/site/CompanyLogos.tsx`.

## איך מחליפים ללוגו אמיתי

1. שמרי את קובץ ה-SVG הרשמי של החברה כאן, בשם באנגלית קטנה עם מקפים:
   `red-hat.svg`, `etoro.svg`, `appsflyer.svg`, `check-point.svg` …
2. ב-`CompanyLogos.tsx`, הוסיפי `file: true` לאותה חברה:

```ts
{ name: "Red Hat", file: true },
```

זהו — הקומפוננטה תטען את הקובץ במקום הוורדמארק המובנה.

היכן משיגים SVG רשמי: בדרך כלל בעמוד "Brand" / "Press Kit" / "Media Kit" באתר
החברה, או ב-Wikipedia (קובץ SVG בערך של החברה).

## חשוב לדעת

- **הלוגואים המובנים הם שחזור**, לא האמנות הרשמית. הם נראים נכון בגודל של קיר
  לוגואים, אבל להדפסה או לרזולוציה גבוהה עדיף קובץ מקורי.
- **אלו סימני מסחר של צד שלישי.** להציג רק חברות שחנה באמת מבצעת עבורן השמות.
  להצגת לוגו של חברה שאינה לקוחה יש חשיפה משפטית.
- להסרת חברה: פשוט למחוק את השורה שלה מהמערך, או להוסיף `hidden: true`.
