# פונט המותג — Ping HL

כדי שכל המערכת תרוץ בפונט Ping (כמו באתר הקיים), הניחי כאן שני קבצים:

- `PingHL-Regular.woff2`
- `PingHL-Bold.woff2`

זהו. ה-CSS כבר מצביע אליהם (`src/app/globals.css`) — ברגע שהקבצים כאן,
כל האתר עובר ל-Ping אוטומטית, כולל הכותרות באנגלית.

עד אז המערכת משתמשת ב-Assistant (עברית) + Poppins (לטינית) — פונטים חופשיים
עם מטריקות דומות מאוד, כך שהמעבר לא יזיז את העיצוב.

המרה מ-TTF/OTF ל-woff2: https://cloudconvert.com/ttf-to-woff2
(הפונט מסחרי — ודאי שיש רישיון web.)
